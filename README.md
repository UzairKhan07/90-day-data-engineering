# 🗓️ 90-Day Data Engineering Roadmap

A self-directed, hands-on journey through core data engineering fundamentals — one project per week, each building on the last.

---

## 📂 Weeks

| Week | Project | Stack |
|---|---|---|
| [Week 3](./week3-docker-postgres) | Bulk-load NYC Taxi data into Postgres via Docker | Docker, PostgreSQL, Python, psycopg2 |
| [Week 4](./week4-airflow-taxi-pipeline) | Orchestrate the same pipeline with Airflow | Apache Airflow, Docker Compose, PostgreSQL |

Each week's folder has its own README with setup instructions, architecture notes, and known limitations.

---

## 🎯 Goal

Build production-adjacent habits early: containerized environments, orchestrated pipelines, externalized secrets, and documentation that another engineer could actually pick up and run.
